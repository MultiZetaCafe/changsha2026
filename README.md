# 第五届多重 zeta 值及相关领域研讨会网站

本仓库包含第五届多重 zeta 值及相关领域研讨会（2026，长沙）的会议网站。

This repository contains the website for the 5th Workshop on Multiple Zeta Values and Related Fields, to be held in Changsha in 2026.

## 网站内容

- 会议简介、组织单位、组委会和工作人员信息
- 注册时间、注册方式和联系人信息
- 已确认报告人名单
- 会议地点、交通路线和地图导航
- 会议海报和相关媒体材料

## Site Contents

- Introduction, organizing institutions, organizing committee, and conference assistants
- Registration information and contacts
- Confirmed speakers
- Venue, transportation routes, and map navigation
- Poster and media materials

## 项目结构

- `index.html`：主页
- `registration/`：注册信息
- `program/`：会议程序和报告人名单
- `directions/`：会议地点和交通信息
- `flyer/`：海报和媒体材料
- `assets/`：图片、样式表、二维码等静态资源
